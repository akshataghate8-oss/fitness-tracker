# FitTrack - Fitness Tracker

A simple responsive fitness tracker website made with **HTML, CSS and JavaScript**.

## Features
- Daily steps tracker
- Water tracker
- Calories burned tracker
- Workout minutes tracker
- Quick workout buttons
- Daily goals and progress bars
- Motivation quotes
- LocalStorage support (data stays in the browser)
- Responsive design for mobile and desktop
- GitHub Pages ready

## Run locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Click **Save**.
7. Wait for GitHub Pages to publish your site.

No PHP, database or server is required.
